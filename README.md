# 智实验 · 学生端

智实验（Smart Lab）是面向大学物理实验教学的智能实验辅助平台。

本分支 `student-frontend` 主要负责**学生端页面、实验工作台以及学生端交互体验**，为学生提供从查看实验任务、记录实验数据，到数据计算、拟合分析和 AI 实验报告生成的一体化实验操作流程。

---

## 学生端功能

### 1. 学生首页
提供实验任务、实验学习、数据分析、班级信息和实验进度等入口。

### 2. 实验任务
学生可以查看当前需要完成的实验任务。当前主要为学生端 UI 和演示数据，后续接入 Supabase 真实任务数据。

### 3. 实验工作台
以「测量金属丝的电阻率」为示例，实现完整的实验操作流程：

```text
实验原理
    ↓
实验数据
    ↓
数据计算
    ↓
拟合曲线
    ↓
AI实验报告
    ↓
提交实验
```

### 4. 实验数据
- 电压 U 数据录入
- 电流 I 数据录入
- 添加/删除数据
- 有效数据判断
- 实验数据状态提示

### 5. 数据计算
- 单组电阻计算
- 平均电阻计算
- 计算结果展示

### 6. 拟合曲线
- 实验数据点绘制
- 动态拟合直线
- 拟合方程
- 拟合斜率
- R²
- X/Y 数字刻度
- 数据线性相关性提示

### 7. AI 实验报告
- AI 实验分析
- 实验数据摘要
- 有效数据组数
- 平均电阻
- 拟合斜率
- R²
- 数据质量提示
- 报告生成状态
- 报告正文展示

目前使用前端演示数据生成，后续接入 AI 服务。

### 8. 通用数据分析
学生端提供独立的数据分析工具页面：

```text
输入 X / Y 数据
      ↓
选择拟合模型
      ↓
进行数据分析
      ↓
查看拟合曲线
      ↓
查看拟合结果
```

具体拟合算法和工具包由项目数据分析模块提供，学生端负责页面展示和接口接入。

### 9. 班级
学生可以查看班级相关信息，真实数据后续通过 Supabase 接入。

### 10. AI 问答
提供学生实验学习过程中的 AI 辅助问答入口，当前完成学生端交互界面。

### 11. 学生设置
包括：
- 个人信息
- 账号设置
- 密码设置
- 通知设置
- 关于平台

## 本地运行

### 安装依赖

```bash
npm install
```

### 配置环境变量

在项目根目录创建 `.env.local`：

```env
NEXT_PUBLIC_SUPABASE_URL=你的 Supabase 项目地址
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=你的 Supabase Publishable Key
```

### 启动项目

```bash
npm run dev
```

访问：

```text
http://localhost:3000
```
